# One-Line Office Jokes

A make.fun entry for the **One-Line Office Jokes** bounty
(`u-markk-st-one-line-office-jokes-a51f2bcc`).

`main.py` writes one original single-line office joke to the harness
output path (`/output/entry.txt`): 1–199 characters, one line, UTF-8,
deterministic and offline.
